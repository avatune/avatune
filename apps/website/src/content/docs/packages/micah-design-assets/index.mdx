Micah Design style SVG assets for avatar generation.

## Description

This package provides SVG assets in micah design style for creating customizable avatars. Assets include various options for hair, eyes, eyebrows, mouth, nose, ears, head shape, and body/clothing.

## Installation

```bash
npm install @avatune/micah-design-assets
```

## Usage

### SVG Paths

```typescript
import { hair, eyes, mouth } from '@avatune/micah-design-assets';
```

### React Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/micah-design-assets/react';
```

### Svelte Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/micah-design-assets/svelte';
```

### Vue Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/micah-design-assets/vue';
```
