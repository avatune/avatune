## Installation

```package-install
@avatune/retro-cartoon-theme
```

## Usage

This theme is available for multiple frameworks: React, Vue, Svelte, Angular, and Vanilla JavaScript.

### React

```tsx
import { Avatar } from '@avatune/react'
import theme from '@avatune/retro-cartoon-theme/react'

function App() {
  return (
    <Avatar
      theme={theme}
      size={300}
      seed="optional-seed-for-random-generation"
    />
  )
}
```

### Vue

```vue
<script setup lang="ts">
import { Avatar } from '@avatune/vue'
import theme from '@avatune/retro-cartoon-theme/vue'
</script>

<template>
  <Avatar
    :theme="theme"
    :size="300"
    seed="optional-seed-for-random-generation"
  />
</template>
```

### Svelte

```svelte
<script lang="ts">
  import { Avatar } from '@avatune/svelte'
  import theme from '@avatune/retro-cartoon-theme/svelte'
</script>

<Avatar
  theme={theme}
  size={300}
  seed="optional-seed-for-random-generation"
/>
```

### Angular

```ts
import { Component } from '@angular/core'
import { Avatar } from '@avatune/angular'
import theme from '@avatune/retro-cartoon-theme/angular'

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [Avatar],
  template: `
    <avatune-avatar
      [theme]="theme"
      [inputSize]="300"
      seed="optional-seed-for-random-generation"
    />
  `,
})
export class AppComponent {
  theme = theme
}
```

### Vanilla JavaScript

```typescript
import { avatar } from '@avatune/vanilla'
import theme from '@avatune/retro-cartoon-theme/vanilla'

const container = document.getElementById('avatar-container')
const svg = avatar({
  theme,
  size: 300,
  seed: 'optional-seed-for-random-generation',
})

container?.appendChild(svg)
```

## Customization

You can override specific avatar parts:

```tsx
<Avatar
  theme={theme}
  size={300}
  hair="pasted2"          // Choose specific hair style
  hairColor="#FF5733"    // Custom hair color
  body="pasted1"     // Choose specific clothing
  bodyColor="#3498DB"    // Custom clothing color
/>
```

## Design Assets

This theme uses Retro Cartoon style SVG assets for creating customizable avatars. Assets include various options for hair, eyes, eyebrows, mouth, nose, ears, head shape, and body/clothing.

The assets are available in the [`@avatune/retro-cartoon-assets`](https://www.npmjs.com/package/@avatune/retro-cartoon-assets) package.

### Using Assets Directly

#### SVG Paths

```typescript
import { hair, eyes, mouth } from '@avatune/retro-cartoon-assets';
```

#### React Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/retro-cartoon-assets/react';
```

#### Svelte Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/retro-cartoon-assets/svelte';
```

#### Vue Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/retro-cartoon-assets/vue';
```
