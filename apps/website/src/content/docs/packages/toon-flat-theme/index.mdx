## Installation

```package-install
@avatune/toon-flat-theme
```

## Usage

This theme is available for multiple frameworks: React, Vue, Svelte, Angular, and Vanilla JavaScript.

### React

```tsx
import { Avatar } from '@avatune/react'
import theme from '@avatune/toon-flat-theme/react'

function App() {
  return (
    <Avatar
      theme={theme}
      size={300}
      seed="optional-seed-for-random-generation"
    />
  )
}
```

### Vue

```vue
<script setup lang="ts">
import { Avatar } from '@avatune/vue'
import theme from '@avatune/toon-flat-theme/vue'
</script>

<template>
  <Avatar
    :theme="theme"
    :size="300"
    seed="optional-seed-for-random-generation"
  />
</template>
```

### Svelte

```svelte
<script lang="ts">
  import { Avatar } from '@avatune/svelte'
  import theme from '@avatune/toon-flat-theme/svelte'
</script>

<Avatar
  theme={theme}
  size={300}
  seed="optional-seed-for-random-generation"
/>
```

### Angular

```ts
import { Component } from '@angular/core'
import { Avatar } from '@avatune/angular'
import theme from '@avatune/toon-flat-theme/angular'

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [Avatar],
  template: `
    <avatune-avatar
      [theme]="theme"
      [inputSize]="300"
      seed="optional-seed-for-random-generation"
    />
  `,
})
export class AppComponent {
  theme = theme
}
```

### Vanilla JavaScript

```typescript
import { avatar } from '@avatune/vanilla'
import theme from '@avatune/toon-flat-theme/vanilla'

const container = document.getElementById('avatar-container')
const svg = avatar({
  theme,
  size: 300,
  seed: 'optional-seed-for-random-generation',
})

container?.appendChild(svg)
```

## Customization

You can override specific avatar parts:

```tsx
<Avatar
  theme={theme}
  size={300}
  hair="beanie"          // Choose specific hair style
  hairColor="#FF5733"    // Custom hair color
  body="halfZip"     // Choose specific clothing
  bodyColor="#3498DB"    // Custom clothing color
/>
```

## Design Assets

This theme uses Toon Flat style SVG assets for creating customizable avatars. Assets include various options for hair, eyes, eyebrows, mouth, nose, ears, head shape, and body/clothing.

The assets are available in the [`@avatune/toon-flat-assets`](https://www.npmjs.com/package/@avatune/toon-flat-assets) package.

### Using Assets Directly

#### SVG Paths

```typescript
import { hair, eyes, mouth } from '@avatune/toon-flat-assets';
```

#### React Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/toon-flat-assets/react';
```

#### Svelte Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/toon-flat-assets/svelte';
```

#### Vue Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/toon-flat-assets/vue';
```
