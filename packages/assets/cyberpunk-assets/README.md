# @avatune/cyberpunk-assets

[![npm version](https://img.shields.io/npm/v/@avatune/cyberpunk-assets)](https://www.npmjs.com/package/@avatune/cyberpunk-assets)
[![npm bundle size](https://img.shields.io/npm/unpacked-size/@avatune/cyberpunk-assets)](https://www.npmjs.com/package/@avatune/cyberpunk-assets)

Cyberpunk style SVG assets for avatar generation.

## Description

This package provides SVG assets in cyberpunk style for creating customizable avatars.

## Installation

```bash
npm install @avatune/cyberpunk-assets
```

## Usage

### SVG Paths

```typescript
import { hair, eyes, mouth } from '@avatune/cyberpunk-assets';
```

### React Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/cyberpunk-assets/react';
```

### Svelte Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/cyberpunk-assets/svelte';
```

### Vue Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/cyberpunk-assets/vue';
```
