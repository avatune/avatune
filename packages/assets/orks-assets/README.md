# @avatune/orks-assets

[![npm version](https://img.shields.io/npm/v/@avatune/orks-assets)](https://www.npmjs.com/package/@avatune/orks-assets)
[![npm bundle size](https://img.shields.io/npm/unpacked-size/@avatune/orks-assets)](https://www.npmjs.com/package/@avatune/orks-assets)

Orks style SVG assets for avatar generation.

## Description

This package provides SVG assets in orks style for creating customizable avatars.

## Installation

```bash
npm install @avatune/orks-assets
```

## Usage

### SVG Paths

```typescript
import { hair, eyes, mouth } from '@avatune/orks-assets';
```

### React Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/orks-assets/react';
```

### Svelte Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/orks-assets/svelte';
```

### Vue Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/orks-assets/vue';
```
