# @avatune/retro-cartoon-assets

[![npm version](https://img.shields.io/npm/v/@avatune/retro-cartoon-assets)](https://www.npmjs.com/package/@avatune/retro-cartoon-assets)
[![npm bundle size](https://img.shields.io/npm/unpacked-size/@avatune/retro-cartoon-assets)](https://www.npmjs.com/package/@avatune/retro-cartoon-assets)

Retro-cartoon style SVG assets for avatar generation.

## Description

This package provides SVG assets in retro-cartoon style for creating customizable avatars.

## Installation

```bash
npm install @avatune/retro-cartoon-assets
```

## Usage

### SVG Paths

```typescript
import { hair, eyes, mouth } from '@avatune/retro-cartoon-assets';
```

### React Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/retro-cartoon-assets/react';
```

### Svelte Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/retro-cartoon-assets/svelte';
```

### Vue Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/retro-cartoon-assets/vue';
```
