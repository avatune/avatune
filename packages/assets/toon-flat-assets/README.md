# @avatune/toon-flat-assets

[![npm version](https://img.shields.io/npm/v/@avatune/toon-flat-assets)](https://www.npmjs.com/package/@avatune/toon-flat-assets)
[![npm bundle size](https://img.shields.io/npm/unpacked-size/@avatune/toon-flat-assets)](https://www.npmjs.com/package/@avatune/toon-flat-assets)

Toon-flat style SVG assets for avatar generation.

## Description

This package provides SVG assets in toon-flat style for creating customizable avatars.

## Installation

```bash
npm install @avatune/toon-flat-assets
```

## Usage

### SVG Paths

```typescript
import { hair, eyes, mouth } from '@avatune/toon-flat-assets';
```

### React Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/toon-flat-assets/react';
```

### Svelte Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/toon-flat-assets/svelte';
```

### Vue Components

```typescript
import { HairShort, EyesBoring, MouthSmile } from '@avatune/toon-flat-assets/vue';
```
